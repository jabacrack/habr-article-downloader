# История изменений

## 3.4.1.3 — 2026-09-26

- Из Firefox-архивов исключены локальные файлы IDE.
- В инструкции добавлен шаг выдачи доступа к `habr.com` после временной установки ZIP: Firefox может не показать запрос разрешения автоматически.

## 3.4.1.2 — 2026-09-26

- Кнопки `.md` и «В Joplin» теперь восстанавливаются, если Habr удаляет их при обновлении разметки статьи. Исправлено исчезновение кнопок в Firefox при включённом uBlock Origin.

## 3.4.1.1 — 2026-09-20

- Добавлена отправка статьи в Joplin Desktop через локальный Web Clipper с выбором блокнота и настройкой сохранения комментариев.
- Добавлена поддержка Firefox и подготовка пакета, исходников и сопроводительных файлов для Firefox Add-ons.
